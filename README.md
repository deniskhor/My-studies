## Как пользоваться

Для чтения откройте нужный ноутбук по ссылке в оглавлении. Для выполнения кода скачайте репозиторий и откройте ноутбук в VS Code с поддержкой Jupyter или в Jupyter Notebook.

В материалах используются NumPy, pandas, matplotlib, seaborn и Plotly. Полная проверка зависимостей и запуска пока не выполнена.

В Telegram можно делиться ссылкой на конкретный ноутбук или на это оглавление после публикации репозитория.

## Текущее состояние

После перемещения файлов нужно проверить пути к данным:

- В ноутбуках EDA и matplotlib остались абсолютные пути к прежней папке `Python`.
- В некоторых ноутбуках pandas чтение файлов пока не учитывает разделение на `notebooks` и `data`.
- Конспект ООП импортирует `Car` из `car.py`; этого файла в учебной папке сейчас нет.
- `learn/pandas/convert.py` обращается к `enable1.txt` по старому пути; исходный файл в этой папке не найден.
- `learn/EDA/predict.py` читает `medical.csv`; этот датасет в учебной папке не найден.

Сохранённые результаты в ноутбуках могут относиться к запуску до перемещения файлов.
